## Como preencher este documento

Quando o usuário fornecer dados comerciais reais (catálogo, preços, fotos, materiais de marca), eles devem ser registrados aqui (ou em um local de dados estruturado equivalente, quando o banco de dados existir) com a data e a origem da informação. Nenhuma sessão de desenvolvimento deve substituir uma linha "pendente de confirmação" por um dado inventado, mesmo como placeholder temporário em tela — placeholders de interface devem ser visualmente identificados como tal (ex.: "Produto Exemplo — dado pendente"), nunca parecer dado real.
